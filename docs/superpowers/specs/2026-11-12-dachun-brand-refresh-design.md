# 大春之道线下实训营市场服务手册：品牌改版设计

## 意图

在保留现有页面内容、交互和信息结构的前提下，将站点改为“大春之道线下实训营市场服务手册”的品牌版本，用用户提供的 logo 和湖蓝色视觉统一页面识别。

## 目标

- 页面标题改为“ 大春之道线下实训营市场服务手册 ”（不含多余空格）。
- 使用用户提供的 logo 替换现有 `assets/logo.png`。
- 将现有主色/强调色体系调整为与 logo 协调的湖蓝色，并保持文字对比度和现有布局。
- 将“总监思维”改为“领导人思维”。
- 在主标题下增加“百战归来再相见！”。
- 其他内容、导航、搜索、复制、切换和数据均不改动。

## 非目标与约束

- 不重写页面架构，不引入新依赖，不改变 GitHub Pages 的静态发布方式。
- 不修改既有业务内容和交互逻辑。
- 新版本单独发布到新的 GitHub 仓库，原仓库不覆盖。

## 实现方式与取舍

1. **推荐：现有单页小范围修改。** 在当前 `index.html` 中更新标题/副标语/文案，并将现有主色替换为湖蓝色；替换 logo 资源。这样改动最小，最能保证既有功能不受影响。
2. **完整设计变量重构。** 先重构全部颜色引用，再改品牌内容。可维护性略好，但对本次小范围改版改动过大。
3. **重做为新前端项目。** 不采用，因为现有静态单页已具备全部功能，会引入不必要的回归风险。

## 验收

- 本地页面可打开，标题、logo、副标语和“领导人思维”均正确显示。
- 页面中的主按钮、标签、选中态和强调内容呈湖蓝色，文字仍清晰可读。
- 现有交互检查脚本通过，Git 工作区只包含本次改版文件。
- 新仓库独立推送成功，并可通过对应 GitHub Pages URL 访问。
